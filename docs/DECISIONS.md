# ثبت تصمیم‌های فنی — هفتاد و هفت سرزمین

| شناسه | تصمیم | مقدار قطعی | وضعیت |
|---|---|---|---|
| O-14 | Backend | Python 3.11+ و FastAPI | تأییدشده |
| O-15 | پایگاه داده | PostgreSQL | تأییدشده |
| O-16 | میزبانی | Liara | تأییدشده |
| O-17 | معماری | Modular Monolith با جداسازی core / api / modules / integrations | تأییدشده |
| O-18 | مرجع داده | سرور مرجع اصلی؛ localStorage فقط کش موقت | تأییدشده |
| A-05 | احراز هویت | initData معتبر بله + Update رسمی contact با شرط contact.user_id == from.id | تأییدشده |

## قواعد امنیتی
1. توکن بازوی بله فقط در Environment Variables بک‌اند نگهداری می‌شود.
2. initData خام در سرور اعتبارسنجی می‌شود؛ initDataUnsafe مدرک هویت نیست.
3. شمارهٔ callback متد requestContact در کلاینت تأییدشده محسوب نمی‌شود.
4. پاداش، موجودی و قفل‌گشایی فقط توسط منطق سرور تعیین می‌شوند.
5. localStorage منبع حقیقت یا مجوز اقتصادی نیست.
6. داده‌های مهاجرتی مرورگر با منشأ legacy ثبت می‌شوند و مبنای پاداش نیستند.

## سیاست‌ها و موارد تست
- عمر حداکثر ۵ دقیقه برای initData سیاست امنیتی پروژه است، نه محدودیت اعلام‌شدهٔ بله.
- نشست API امضاشده و قابل ابطال است.
- ۷۷ سرزمین در مدل جهان ثبت می‌شوند؛ نام ۱۳ دروازهٔ فعلی حفظ و نام‌گذاری بقیه موقت است.
- قالب واقعی Update contact، ثبت webhook با URL دارای secret و رفتار Mini App در نسخه‌های واقعی بله باید پیش از انتشار عملیاتی تست شوند.
