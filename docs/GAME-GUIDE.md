# راهنمای اجرا و بازی — هفتاد و هفت سرزمین (نسخهٔ ۰٫۳)

## اجرا

بازی **تک‌فایل آفلاین** است: `game/index.html` را در مرورگر باز کنید (کافی است دو بار کلیک/لمس).
نیازی به سرور، نصب یا اینترنت نیست.

- فقط وابستگی اختیاری: فونت وب Vazirmatn از CDN — بدون اینترنت، فونت سیستم جایگزین می‌شود.
- موبایل اندروید: فایل را به گوشی منتقل کنید و در Chrome باز کنید؛ کنترل لمسی (جوی‌استیک + دکمه‌ها).
- دسکتاپ: حرکت با WASD/کلیدهای جهت.
- ذخیرهٔ پیشرفت خودکار است (localStorage دستگاه). کلید: `hs77_darvazeha_v1`
  (مستقل از بازی v1 و نمونهٔ اولیه).

## توسعه (ساخت از منبع)

```bash
python3 scripts/build.py        # src/ → game/index.html
node --check src/js/*.js        # بررسی نحوی
```

ساختار منبع: `src/js/00-util → 05-data → 10-state → 20-engine → 30-render → 40-ui → 50-main`
(ترتیب اتصال مهم است). افزودن سرزمین/کالا/مأموریت = افزودن داده در `src/js/05-data.js`.

## آزمون خودکار

```bash
python3 tests/verify_game.py       # محصول — ۳۵ بررسی (شبیه‌سازی اندروید لمسی)
python3 tests/verify_prototype.py  # نمونهٔ اولیه — ۲۲ بررسی
python3 scripts/verify.py          # v1 — ۱۶ بررسی (نیازمند سرور ۸۱۲۳: python3 -m http.server 8123)
```

نتایج فعلی: ۳۵/۳۵ · ۲۲/۲۲ · ۱۶/۱۶ PASS. آزمون روی دستگاه اندروید **واقعی** انجام نشده است
(دسترسی به گوشی نبود)؛ شبیه‌سازی جای آن گذاشته نشده.

## راهنمای بازی (چرخهٔ کامل)

1. **آغاز سفر:** نام + پرچم انتخاب کنید → شناسهٔ یکتای بازیکن ساخته می‌شود.
2. **دریای شیشه‌ای (سرزمین ۱):** با جوی‌استیک بگردید؛ صخره‌ها سنگ، درخت‌ها چوب می‌دهند
   (مینی‌گیم «ضربه به‌موقع» — M4). در **کارگاه** ابزار سنگی بسازید (۲ سنگ + ۱ چوب) و
   در **کارنامه** تجهیزش کنید (هر ضربهٔ دوم +۱).
3. **مأموریت اصلی ۱ «ابزار برای ناخدا»:** از ناخدا بپذیرید، ابزار بسازید، تحویل دهید
   (+۲۰ سکه) → **سرزمین ۲ روی نقشه گشوده می‌شود.**
4. **بازار محلی (چادر):** فروش سنگ/چوب، سفارش کاروان، خرید دانهٔ گندم.
5. **مزرعه:** دانه بکارید (~۷۵ ثانیه رشد قطعی) → برداشت خوشهٔ طلایی → فروش.
6. **مأموریت فرعی «فانوس‌های گمشده»:** سه فانوس ساحلی را پیدا کنید → **جامهٔ فانوس‌بان**
   (سرعت +۱۲٪) — در کارنامه بپوشید.
7. **پازل دروازهٔ مرجانی:** سه سنگ‌مرجان را بردارید و از شرق به غرب (درشت، میانه، ریز)
   بچینید → صندوق با محتوای ثابت.
8. **جنگل نقره‌ای (سرزمین ۲):** چوب نقره‌ای جمع کنید (۶ عدد) + ابزار سنگی → تحویل به
   بانفشهٔ نگهبان (+۳۰ سکه) → شرط سرزمین ۳ کامل می‌شود (محتوایش پس از تصمیم A1 ساخته می‌شود).
9. **شب و روز:** شب‌ها تاریکی و نور فانوس‌ها؛ ساکنان گرد آتشگاه جمع می‌شوند (NPC —
   بازیکن واقعی دیگر حاضر نیست؛ نسخهٔ آنلاین نیازمند سرور است).

## قواعد اقتصادی (شفاف)

- سکه فقط از کار واقعی (مأموریت، فروش محصول) — **هیچ فروش توکن، قمار یا خرید شانس‌محور نیست.**
- پاداش هر مأموریت فقط یک‌بار (D7) — همهٔ رویدادها با شناسهٔ یکتا در دفترکل زنجیره‌دار ثبت و
  در پنل «سرزمین» راستی‌آزمایی می‌شوند.
- همهٔ اعداد [آزمایشی] (D12) — مدل نهایی قیمت‌گذاری با تصمیم کارفرما (A4/A10).
