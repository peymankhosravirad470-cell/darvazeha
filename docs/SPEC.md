# مشخصات پروژه — نسخهٔ ۲ (بازسازی از صفر)

> وضعیت این سند: بازسازی‌شده از گفتگوهای این جلسه. هر بند با نشانگر وضعیت مشخص شده است:
> ✅ = تأیید صریح کاربر | ⚠️ = در انتظار تأیید یا اطلاعات تکمیلی از کاربر
> **هیچ بندی از این سند به‌صورت فرضی به کد تبدیل نمی‌شود مگر با تأیید.**

## ۱. هویت بازی

| مورد | وضعیت |
|---|---|
| نام بازی | ⚠️ نامشخص — در نسخهٔ قبلی موجود بوده؛ از کاربر پرسیده شود |
| زبان رابط | ✅ فارسی، چیدمان RTL |
| مخاطب | ⚠️ تأیید نشده (بر اساس شخصیت‌های کپسولی، به‌احتمال زیاد کودک/نوجوان) |

## ۲. ساختار صفحات

| صفحه | وضعیت | توضیح |
|---|---|---|
| دروازه‌ها (خانه) | ✅ | ۱۳ دروازه به‌صورت کارت/پنل شیشه‌ای |
| نقشهٔ جهان | ✅ | نمای کلی مسیر؛ پیشرفت دروازه‌ها قابل مشاهده |
| پروفایل | ✅ | وضعیت بازیکن، پیشرفت، آمار |
| صحنهٔ اکتشاف | ✅ | داخل هر دروازه؛ شخصیت‌های کپسولی + دستهٔ حرکت (جوی‌استیک لمسی) |

## ۳. دروازه‌ها

- تعداد: ✅ **۱۳ دروازه**
- دروازهٔ تأییدشده: ✅ **«دریای شیشه‌ای»** (صحنهٔ اکتشاف دارد: شخصیت‌های کپسولی، دستهٔ حرکت)
- نام ۱۲ دروازهٔ دیگر: ⚠️ در دسترس نیست — لیست اصلی باید از کاربر/پیمان گرفته شود؛
  در غیر این صورت لیست پیشنهادی ساخته و برای تأیید ارائه می‌شود
- **بدون شخصیت‌سازی** ✅ (قید صریح کاربر)

## ۴. محتوای هر دروازه

| بخش | وضعیت | توضیح |
|---|---|---|
| مأموریت | ✅ وجود دارد | جزئیات ساختار مأموریت ⚠️ |
| مینی‌گیم | ✅ وجود دارد | نوع مینی‌گیم هر دروازه ⚠️ (برای «دریای شیشه‌ای»: اکتشاف با جوی‌استیک) |
| پیش‌بینی کامل | ✅ وجود دارد | ساختار و متن پیش‌بینی‌ها ⚠️ |
| QR تستی | ✅ وجود دارد | عملکرد دقیق QR (اشتراک؟ ورود؟) ⚠️ |

## ۵. سیستم بصری (تصمیم‌های تأییدشده در این جلسه)

- **سبک کلی:** گلس‌مورفیسم تاریک
  - گرادیان پس‌زمینه: سرمه‌ای ↔ بنفش
  - پنل‌ها: شیشه‌ای نیمه‌شفاف با بلور (backdrop-blur) و درخشش نئونی لبه‌ها
  - سایه‌های عمق‌دار، انیمیشن‌های سبک و نرم
- **الزام کاربر:** ارتقای بصری روی **همهٔ ۱۳ دروازه** اعمال شود، نه فقط «دریای شیشه‌ای»
- **صحنهٔ «دریای شیشه‌ای»:** بافت آب — گرادیان عمق + موج‌های لطیف متحرک + بازتاب نور
  (بقیهٔ جزئیات محیطی مثل ذرات شناور و سایهٔ شخصیت‌ها بعداً قابل افزودن است)
- آیکون‌ها و تایپوگرافی ارتقایافته؛ بدون بافت تخت تک‌رنگ

## ۶. تصمیم‌های فنی

| مورد | تصمیم | وضعیت |
|---|---|---|
| شکل خروجی | تک‌فایل HTML مستقل (`index.html`) | ✅ انتخاب کاربر |
| فناوری | HTML + CSS + JavaScript خالص (بدون وابستگی خارجی تا حد امکان) | ⚠️ پیش‌فرض پیشنهادی |
| ذخیرهٔ پیشرفت | localStorage | ⚠️ پیش‌فرض پیشنهادی |
| کنترل صحنهٔ اکتشاف | جوی‌استیک لمسی + کلیدهای جهت کیبورد | ⚠️ پیش‌فرض پیشنهادی |
| نسخه‌گذاری فایل خروجی | نام فایل نسخه‌دار در پوشهٔ تحویل (مثلاً `game-v2.html`) تا کش مرورگر باعث سردرگمی نشود | ✅ توافق‌شده |

## ۷. فرایند توسعه (الزام صریح کاربر)

1. پس از **هر** تغییر کوچک یا بزرگ: کامیت فوری، نه تجمیعی در پایان
2. به‌محض دریافت دسترسی GitHub: اتصال remote و push کامل تاریخچه؛ پس از آن بعد از هر کامیت، push
3. گزارش هر مرحله شامل: نام فایل‌های تغییر یافته + hash کامیت‌ها برای راستی‌آزمایی روی GitHub
4. هیچ کدی فقط در محیط موقت session باقی نمی‌ماند
