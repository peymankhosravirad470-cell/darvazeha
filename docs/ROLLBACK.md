# بازگشت به نسخهٔ قبلی (Rollback) — اتصال جهان تارگون

## وضعیت پایهٔ قابل بازگشت

- نسخهٔ استقراریافتهٔ پیش از این مرحله: **Release v6** از کامیت `581a6f7` روی `main`
- پشتیبان روی GitHub: تگ/شاخهٔ `backup/release-v6-main` → `581a6f7`
- این مرحله **هیچ migration دیتابیس** اضافه نکرده است؛ بازگشت، اسکیمای
  دیتابیس و داده‌ها را تغییر نمی‌دهد.

## روش بازگشت سریع (در صورت خطای بحرانی پس از استقرار v7)

1. بازیابی نسخهٔ قبلی از GitHub:
   ```bash
   git fetch origin
   git checkout backup/release-v6-main
   ```
2. استقرار دوباره با همان تنظیمات تأییدشدهٔ v6 (context ریشه، Dockerfile بک‌اند، پورت ۸۰۰۰):
   ```bash
   liara deploy --app darvazeh-ha --platform docker -f backend/Dockerfile -b iran --port 8000 \
     --api-token "$(cat ~/.config/darvazeha/liara.token)"
   ```
3. راستی‌آزمایی سلامت:
   ```bash
   curl -f https://darvazeh-ha.liara.run/health   # → {"status":"ok",...}
   ```
4. کنترل ربات: `getMe` و `getWebhookInfo` — وب‌هوک به دامنه اشاره می‌کند نه
   به نسخه؛ با بازگشت ایمیج، وب‌هوک و توکن ربات دست‌نخورده می‌مانند.

## اثر بازگشت بر تجربهٔ کاربر

- دکمهٔ «🎮 ورود به بازی» و همهٔ قابلیت‌های قبلی مینی‌اپ سر جای خودشان می‌مانند.
- در نسخهٔ v6 مسیر `/game/index.html` وجود ندارد → کارت «🌍 جهان تارگون»
  (اگر مینی‌اپ قدیمی کش‌شده نمایش داده شود) به 404 می‌خورد؛ بقیهٔ صفحه سالم است.
- هیچ دادهٔ بازیکنی (موجودی، پیشرفت، دفترکل) در این بازگشت تغییر نمی‌کند.
