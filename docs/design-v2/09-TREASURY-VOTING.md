# سند ۰۹ — خزانهٔ جمعی و رأی‌گیری ریسک

> **نسخهٔ v2.0 پیش‌نویس برای تصویب | ۲۰۲۶-۱۱-۰۲ | وابسته به: سند ۰۲ (دفترکل)، سند ۰۸ (هماورد)، سند ۱۰ (حکومت)، سند ۱۴ (ممیزی)**
> اصل انضمامی [قطعی]: **فقط مازاد داوطلبانهٔ خزانهٔ جمعی می‌تواند در معرض ریسک هماورد قرار گیرد. دارایی شخصی بازیکنان تحت هیچ شرایطی اجباری در معرض خطر نیست.**

---

## ۱. هدف

خزانهٔ جمعی را به‌عنوان «جیب مشترک داوطلبانه» با حکمرانی شفاف طراحی کردن: درآمد مشخص، هزینهٔ مصوب، ریسک فقط با رأی آگاهانه، و ثبت قابل ممیزیِ همهٔ تصمیم‌ها.

## ۲. منابع خزانه [پیشنهادی — نیازمند تصویب]

| منبع | شرح |
|---|---|
| سهم کارمزد بازار محلی | درصدی از کارمزد بازار به خزانهٔ سکونتگاه (سند ۰۵ §۶) [عدد آزمایشی] |
| مشارکت داوطلبانهٔ اعضا | فقط با کنش صریح بازیکن؛ هرگز کسر خودکار |
| درآمد پروژه‌های جمعی | سود خدمات سکونتگاه (انبار، مسیر تجاری) |
| بودجهٔ سطح بالاتر | یارانهٔ حکومتی برای پروژه‌های مشترک (سند ۱۰) |

## ۳. ساختار خزانه

```
خزانه = موجودی آزاد + مازاد تعریف‌شدهٔ مصوب
موجودی آزاد: هزینه‌های جاری (نگهداری، تعمیر زیرساخت)
مازاد: بخشی که صراحتاً و با رأی «مازاد» اعلام شده است
رزرو ریسک: بخشی از مازاد که برای یک هماورد مشخص رأی گرفته و قفل شده
```

**تعریف «مازاد» [پیشنهادی]:** مبلغی که پس از تأمین هزینه‌های جاری دورهٔ بعد، صراحتاً با رأی به «مازاد» منتقل می‌شود. پیش‌فرض: **هیچ چیز مازاد نیست** تا اثبات برعکس — این پیش‌فرض محافظت‌کننده است.

## ۴. فرایند اختصاص مازاد به ریسک هماورد [قطعی از دستور — ۸ گام]

| # | گام | سازوکار |
|---|---|---|
| ۱ | مقدار دقیق اعلام شود | پیشنهاد رسمی با عدد دقیق و سقف |
| ۲ | پیامد احتمالی توضیح داده شود | متن الزامی «اگر ببازیم چه می‌شود» + «اگر ببریم چه می‌شود» |
| ۳ | قوانین پیش از رأی نمایش داده شوند | سند رأی ثابت و غیرقابل تغییر پس از انتشار |
| ۴ | رأی‌گیری آگاهانه برگزار شود | دورهٔ رأی [عدد آزمایشی]؛ نمایش خلاصهٔ استدلال هر دو طرف |
| ۵ | حد نصاب مشارکت رعایت شود | حد نصاب فعال‌ها [عدد آزمایشی]؛ عدم‌نصاب = رد پیشنهاد (پیش‌فرض رد) |
| ۶ | نتیجه ثبت و قابل ممیزی باشد | رکورد `Vote` با گزینه، زمان، شمارش، امضا؛ بدون رأی پنهان |
| ۷ | مقدار اختصاص‌یافته سقف مشخص داشته باشد | سقف نسبت به مازاد [عدد آزمایشی: حداکثر بخشی از مازاد]؛ سقف مطلق دوره |
| ۸ | هیچ تغییری خارج از محدودهٔ رأی مجاز نباشد | مقدار/شرط ریسک پس از تصویب قفل می‌شود؛ اصلاح = رأی جدید |

## ۵. نتیجهٔ ریسک — فقط همین مقدار

- **پیروزی:** بازگشت رزرو + پاداش مصوب از پاداش هماورد (به خزانه، نه مستقیم به افراد بدون توزیع مصوب).
- **شکست:** فقط همان مقدارِ رأی‌گرفته طبق قوانین اعلام‌شده قابل کاهش/مصرف است [قطعی]؛ مابقی خزانه دست‌نخورده.
- **هیچ مصادرهٔ پنهان یا اجباریِ دارایی شخصی مجاز نیست [قطعی].** فهرست محافظت‌شدهٔ کامل: سند ۰۸ §۳.

## ۶. نظارت و ممیزی

- همهٔ جابه‌جایی‌های خزانه `LedgerEntry` با ترک `COLLECTIVE` و مرجع `vote_id`/`war_id`/`project_id` دارد.
- صفحهٔ عمومی خزانه: موجودی آزاد، مازاد مصوب، رزروهای فعال، تاریخچهٔ تصمیم‌ها (سند ۱۳).
- هر رأی قابل بازبینی توسط هر عضو؛ اعتراض به فرایند رأی به مرجع حل اختلاف (سند ۱۰ §نظارت).

## ۷. وضعیت‌ها

```
رأی: PROPOSED → PUBLISHED → OPEN → QUORUM_MET | QUORUM_FAILED → APPROVED | REJECTED → EXECUTED | ARCHIVED
رزرو ریسک: RESERVED → AT_RISK (در جریان هماورد) → SETTLED_WIN (بازگشت+سود مصوب) | SETTLED_LOSS (کسر طبق قاعده) → ARCHIVED
```

`EXECUTED` بدون رکورد رأی معتبر ممکن نیست؛ سازگاری رزرو ≤ مازاد در هر لحظه [قطعی].

## ۸. ریسک‌ها

| ریسک | کنترل |
|---|---|
| دستکاری رأی توسط مسئولان | شمارش از دفتر رأی امضاشده؛ نمایش عمومی جزئیات |
| فشار اجتماعی به رأی مثبت | رأی مخفی-محسوس برای افراد (نتیجه فقط تجمیعی) [پیشنهادی] |
| مازاد صوری | تعریف سخت‌گیرانهٔ §۳؛ سازگاری با هزینه‌های جاری |
| خزانهٔ خالی و انگیزهٔ صفر | بودجهٔ سطح بالاتر + پاداش مشارکت بازنده |

## ۹. تست پذیرش (خلاصه — سناریو ۱۹ سند ۱۵)

1. رأی بدون حد نصاب → رد؛ هیچ رزروی شکل نگیرد. ۲. رزرو > مازاد غیرممکن. ۳. تغییر شرط ریسک پس از تصویب رد شود. ۴. شکست فقط تا سقف رزرو کسر کند. ۵. هر عضو تاریخچهٔ رأی را ببیند.

## ۱۰. نیازمند تصویب کارفرما

1. منابع خزانه و نرخ سهم کارمزد (§۲).
2. تعریف سخت‌گیرانهٔ «مازاد» (§۳).
3. حد نصاب، دورهٔ رأی، سقف رزرو.
4. رأی تجمیعی-نمایشی به‌جای رأی عمومی فردی (§۸).
