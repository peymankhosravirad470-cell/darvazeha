## ۱. کارکردها در یک نگاه

| | بازار محلی | بازار عمومی |
|---|---|---|
| کارکرد [قطعی] | تجارت کالاهای تولیدی و مصرفی حرفه‌ها | مبادلهٔ اقلام کمیاب، ویژه و کلکسیونی |
| اثر [قطعی] | تقویت زنجیرهٔ تولید · درآمد مستقیم تولیدکننده · فعالیت اقتصادی سکونتگاه | جایگاه، مجموعه‌سازی، اقتصاد کمیابی |

## ۲. قواعد مشترک هر دو بازار [قطعی از دستور]

| مؤلفه | شرح |
|---|---|
| شناسهٔ واحد بازیکن | همهٔ کنش‌ها به `player_id` واحد |
| کیف پول واحد | یک موجودی، دو «فضای خرید» متفاوت |
| دفترکل واحد توکن | هر معاملهٔ هر دو بازار در یک دفترکل با برچسب `market = LOCAL | PUBLIC` |
| شناسهٔ یکتای معامله | `txn_*` سراسری |
| سیستم ثبت رویداد | همهٔ کنش‌ها رویداد ساختاریافته |
| کنترل تقلب | همان موتور سیگنال (سند ۱۱) با قواعد متمایز هر بازار |
| کنترل مالکیت آیتم | رزرو/انتقال از یک موتور انبار |
| سازوکار حل اختلاف | یک مرجع، قواعد متمایز |
| گزارش مالی | گزارش هر دو بازار تفکیک‌شده |

**متفاوت‌ها [قطعی]:** قوانین قیمت‌گذاری، نوع کالا، دسترسی و محدودیت عرضه.

## ۳. Market Eligibility Policy (سیاست شایستگی بازار) [پیشنهادی — نیازمند تصویب ساختار]

هر «نوع کالا» باید یک سیاست مصوب داشته باشد؛ بدون سیاست، وارد هیچ بازاری نمی‌شود [قطعی]. فیلدها:

| فیلد | مقادیر نمونه |
|---|---|
| بازارهای مجاز | فقط محلی / فقط عمومی / هر دو (با قواعد هرکدام) |
| چه کسی عرضه می‌کند | سازندهٔ اصلی / مالک فعلی / فقط درون رویداد |
| چه کسی می‌خرد | همه / سکونتگاه خودی / حداقل سطح/سابقه |
| سقف/کف قیمت | نرخ پایه ± دامنه؛ یا مرز ثابت |
| قابل انتقال؟ | بله / فقط یک‌بار / خیر (bind to owner) |
| قابل مصرف/نابودی؟ | بله / خیر |
| قابل استفاده در هماورد؟ | بله / خیر (کالای رقابتی غیرمجاز) |
| سابقهٔ مالکیت لازم؟ | حداقل X روز نگهداری پیش از عرضهٔ عمومی [عدد آزمایشی] |

## ۴. انتقال از بازار محلی به عمومی [پیشنهادی — نیازمند تصویب، گزینهٔ A8 سند ۱۷]

**گزینهٔ پیشنهادی: «ارتقای محدود» نه «انتقال آزاد»**

- فقط گروه مشخصی از اقلام (whitelist): آثار صنعتگر با کیفیت A/S · آیتم‌های رویدادِ برگشت‌پذیر به عمومی · اقلام با provenance کامل.
- شرایط: سیاست شایستگی آن قلم باید «عمومی» را مجاز بداند + سابقهٔ مالکیت حداقلی + کارمزد ارتقا (sink) [عدد آزمایشی].
- اثر یک‌طرفه است: اقلام عمومی به محلی برنمی‌گردند (ساده‌سازی مقاوم در برابر سوءاستفاده).
- **گزینهٔ رقیب:** ممنوعیت کامل انتقال — ساده‌تر و ضدتقلب‌تر، اما بخشی از ارزش‌آفرینی صنعتگر/رویداد را می‌بُرد.
- پیامدها در سند ۱۶ جدول‌بندی شده است.

## ۵. جریان دادهٔ مشترک (نمای ساده)

```
                 ┌──────────── Engine انبار/رزرو مشترک ────────────┐
                 │  free / reserved / locked · ownership history   │
                 └───────────┬─────────────────────┬───────────────┘
                    بازار محلی │                     │ بازار عمومی
              (فهرست محلی، نرخ پایهٔ محلی)     (فهرست سراسری، سقف/خنک‌شدن)
                 └───────────┬─────────────────────┬───────────────┘
                             ▼                     ▼
              ┌──────────── دفترکل واحد + موتور ضدتقلب + حل اختلاف ────────────┐
```

## ۶. تست پذیرش (خلاصه)

1. کالای بدون سیاست در هیچ بازار ثبت نشود؛ ۲. قلم غیر-whitelist در مسیر ارتقا رد شود؛ ۳. گزارش مالی دو بازار تفکیک‌شده تولید شود؛ ۴. رزرو در دو بازار هم‌زمان دوبرابر مصرف نشود.

## ۷. نیازمند تصویب کارفرما

1. ساختار Eligibility Policy (§۳) و مالک مصوبهٔ آن (پیشنهاد: کارفرما به‌عنوان مرجع نهایی طراحی).
2. گزینهٔ «ارتقای محدود» یا «ممنوعیت کامل» (§۴).
3. کارمزد ارتقا و سابقهٔ مالکیت حداقلی.
