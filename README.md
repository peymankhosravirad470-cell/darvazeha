# بازی دروازه‌ها (نام موقت — در انتظار تأیید کاربر)

بازی تعاملی فارسی (RTL) با تم سفر میان ۱۳ دروازه. این مخزن تنها مرجع رسمی کد است؛
**هیچ کدی فقط داخل محیط موقت session نگه داشته نمی‌شود** — پس از هر تغییر، commit و
(به‌محض اتصال GitHub) push انجام می‌گیرد.

## صفحات اصلی

- **دروازه‌ها** — صفحهٔ خانه با ۱۳ دروازه
- **نقشهٔ جهان** — نمای کلی مسیر سفر
- **پروفایل** — وضعیت بازیکن و پیشرفت
- **صحنهٔ اکتشاف** — داخل هر دروازه؛ با شخصیت‌های کپسولی و دستهٔ حرکت (جوی‌استیک)

## مشخصات کلیدی

- ۱۳ دروازه؛ هر دروازه شامل: مأموریت + مینی‌گیم + پیش‌بینی کامل
- بدون شخصیت‌سازی
- QR تستی
- سبک بصری: **گلس‌مورفیسم تاریک** (گرادیان سرمه‌ای↔بنفش، پنل‌های شیشه‌ای بلور، درخشش لبه‌ها)
- خروجی نهایی: **تک‌فایل HTML مستقل** (`index.html` — با دابل‌کلیک اجرا می‌شود)

مشخصات کامل و وضعیت تأیید هر بند: [`docs/SPEC.md`](docs/SPEC.md)

## اجرا

فایل `index.html` را در مرورگر باز کنید. نیازی به سرور یا نصب چیزی نیست.

## فرایند توسعه (الزام)

1. هر تغییر کوچک یا بزرگ ← بلافاصله `git commit`
2. به‌محض اتصال remote ← بعد از هر کامیت، `git push`
3. شمارهٔ کامیت (hash) هر مرحله در گزارش تحویل ذکر می‌شود تا روی GitHub قابل راستی‌آزمایی باشد
