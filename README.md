# هفتاد و هفت سرزمین

بازی تعاملی فارسی (RTL) با تم سفر میان سرزمین‌ها. نسخهٔ رابط فعلی، اسکلت ساختاری v1 با ۱۳ کارت دروازه و صحنهٔ نمونهٔ «دریای شیشه‌ای» است.

> نام مخزن `darvazeha` به‌دلایل تاریخی حفظ شده است؛ نام رسمی محصول «هفتاد و هفت سرزمین» است.

## وضعیت انتشار

- مخزن GitHub وجود دارد؛ **استقرار عمومی و انتشار روی دامنه هنوز انجام نشده است**.
- Frontend به SDK بله و API سروری متصل شده است.
- Backend و دیتابیس روی Liara هنوز مستقر/پیکربندی نشده‌اند؛ بنابراین ورود و همگام‌سازی ابری فقط پس از تنظیم رازها و استقرار فعال می‌شود.
- بازکردن مستقیم `index.html` در مرورگر، پیش‌نمایش محلی است و هویت بله یا همگام‌سازی سروری ایجاد نمی‌کند.

## قابلیت‌های فعلی رابط

- ۱۳ کارت دروازه و نقشهٔ ۱۳ گره‌ای فعلی
- پروفایل بازیکن و آمار اولیه
- صحنهٔ اکتشاف نمونهٔ «دریای شیشه‌ای»
- مینی‌گیم تعادل با آزمون‌های Playwright
- اتصال Mini App به SDK بله، ورود با initData، بارگذاری وضعیت سرور و درخواست تأیید موبایل
- انتقال اختیاری سابقهٔ localStorage با رضایت بازیکن؛ دادهٔ قدیمی پاداش یا قفل‌گشایی معتبر ایجاد نمی‌کند

**محدودیت محتوایی:** تنها دروازهٔ نخست محتوای نمونه دارد. موتور کامل مأموریت، پاداش، بازشدن دروازه‌ها و QR واقعی هنوز پیاده‌سازی نشده‌اند.

## جهان ۷۷ سرزمینی

Backend برای ۷۷ سرزمین رکورد ایجاد می‌کند. نام ۱۳ دروازهٔ فعلی حفظ شده است؛ نام ۶۴ سرزمین دیگر فعلاً موقت است. در نسخهٔ فعلی فقط سرزمین نخست منتشر/گشوده است. مفهوم ۷۷ سرزمین با ۱۳ دروازهٔ رابط فعلی یکسان نیست.

## Backend و مینی‌اپ بله

- Backend: Python 3.11+ / FastAPI / SQLAlchemy
- Database: PostgreSQL
- Hosting مصوب: Liara؛ استقرار هنوز انجام نشده
- معماری: Modular Monolith
- تصمیم‌های فنی تأییدشده: [docs/DECISIONS.md](docs/DECISIONS.md)
- راهنمای Backend و استقرار: [backend/README.md](backend/README.md)
- مشخصات و وضعیت آزمون‌ها: [docs/SPEC.md](docs/SPEC.md)

## ذخیره‌سازی

در Mini App، سرور مرجع اصلی داده است و `localStorage` فقط کش موقت و منبع انتقال اختیاری سابقهٔ قدیمی است. پیشرفت‌های اقتصادی یا قفل‌گشایی از کلاینت پذیرفته نمی‌شوند. رویدادهای مینی‌گیم فعلاً با برچسب `client_unverified` ثبت می‌شوند و پاداش ندارند.
